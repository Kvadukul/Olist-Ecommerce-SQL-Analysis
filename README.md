# Olist Brazilian E-Commerce Analytics Pipeline

An end-to-end data analytics project analyzing real-world Brazilian e-commerce data using SQL and relational database management.

## Project Overview
This project explores customer behavior, product category performance, and logistics/delivery efficiency using the Olist e-commerce dataset (hosted in a local SQLite database via DBeaver).

## Repository Structure & Scripts
- **`Finances.sql`**: Analyzes platform financial metrics and revenue distribution.
- **`Delivery_Stats.sql`**: Evaluates logistics performance, tracking on-time vs early vs late delivery rates across all 27 Brazilian states.
- **`Most_Profitable_Product.sql`**: Ranks product categories by total sales volume and revenue generation.
- **`Customer_Retention.sql`**: Executes a customer RFM (Recency, Frequency, Monetary) segmentation model to identify high-value and repeat buyers.

##  Tech Stack
- **Database / Querying**: SQLite, DBeaver
- **Language**: SQL (Aggregations, JOIN`s, CASE statements, window/date functions)
- **Version Control**: Git & GitHub


Dataset sourced from the Olist Brazilian E-Commerce dataset on Kaggle
